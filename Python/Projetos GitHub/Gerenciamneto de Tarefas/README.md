Um código simples em Python, onde gerenciamos as tarefas diárias, sendo possível adicionar tarefas, ver as tarefas, remover tarefas e enfim, finalizar o programa.

    Começa com uma lista vazia chamada tarefas.

        Loop contínuo que exiba um menu com 4 opções:

            [1] Adicionar uma nova tarefa

            [2] Ver as tarefas pendentes

            [3] Concluir (remover) uma tarefa

            [4] Sair do programa

        Se digitar 1, peça o nome da tarefa e adicione na lista.

        Se digitar 2, exiba a lista de tarefas atual.

        Se digitar 3, peça o nome da tarefa que foi concluída e remova-a da lista.

        Se digitar 4, encerre o programa.
